# 法務トリガー表

電工くんの法務対応（利用規約・プライバシーポリシー・公開範囲の説明）は、
2026-10-05 時点の次の前提に合わせた**最小限**として作られている。

- 利用料金は無料 / 利用者は事業者に限る / 登録は30社程度のパイロット段階
- 解析・広告のタグなし / 決済機能は未実装
- 個人データの保存先は日本（Supabase 東京リージョン）
- 当社は契約当事者にならず、マッチング成立までが役務の範囲

**前提が変わると対応が不足する。** 該当する実装や方針変更に着手する前に、下の該当節だけを読む。

## 索引（該当する節だけ読む）

- **A. 課金・お金** … 有料化、決済、手配代行モデル
- **B. 計測・広告** … 解析タグ、外部埋め込み
- **C. 扱うデータ** … 入力欄の追加、公開範囲の変更、ファイル、チャット
- **D. 機能・運営** … 退会、メール配信、取材、会員数、ドメイン、DB変更
- **E. 外部環境** … 漏えい、法改正、開示請求、規約改定

## 更新ルール

- 該当する変更を行ったら、その行を実施済みに更新する。新しいトリガーに気づいたら行を足す
- 公開リポジトリに置くため、**本人確認の手順や運用上の弱点は書かない**（社内の非公開な場所で管理する）

| 決済情報を外部に預ける | ポリシーの外部サービスと安全管理措置を更新。カード番号を自社で保持しない設計であることを明記 | 個情法23条 |

## B. 計測・広告

電工くんはマッチングサービスなので、外部送信規律の対象になる（総務省 外部送信規律FAQ 問2-6）。外部に情報を送る仕組みを足すときは、ポリシー第10項に「送信先・送信される情報・利用目的」を追記する。

| きっかけ | すべきこと | 根拠 |
|---|---|---|
| 解析・ヒートマップ・広告タグを入れる | ①送信先・送信される情報・利用目的をポリシー第10項に追記 ②ポリシー第10項の「解析・広告の Cookie は使っていない」を書き替え ③同意取得が必要な形式かを判断（バナーの要否） | 電通事業法27条の12 |
| 外部のフォーム・チャット・配信ツールを埋め込む | 上記に加え、ポリシーの外部サービスに追加（所在国とサーバ所在国） | 同／個情法32条1項4号 |
| 第三者のコンテンツを新たに埋め込む | 第三者Cookieが設置されるため同じ検討。動画（YouTube）は youtube-nocookie.com を使い、ポリシー第10項で公表済み | 同上 |

## C. 扱うデータ

| きっかけ | すべきこと | 根拠 |
|---|---|---|
| 新しい入力欄を1つでも追加する | ①ポリシーの「取得する情報」と「利用目的」に追記 ②公開範囲（未ログイン／会員／マッチ相手／管理者）を決めて入力画面に明記 ③既存会員への案内が必要かを判断 | 個情法17・21条 |
| 公開範囲を変える（非公開→公開など） | 本人の同意の根拠を確認。既存データは案内して選べる状態にする。**黙って公開範囲を広げない** | 個情法27条 |
| ファイルアップロードを追加 | ①写真に人や現場が写る場合の同意 ②図面や見積書に施主の情報が入る前提で規約の禁止条項を更新 ③保存先をポリシーに追加 ④閲覧できる範囲の設計（URLの有効期限など） | 個情法23・27条 |
| チャット機能を追加 | ①会話内容の保存期間と運営が閲覧する条件をポリシーに明記 ②第三者の個人情報が書き込まれる前提の禁止条項 ③通信の秘密（電気通信事業の届出の要否）を確認 | 電通事業法4条 |
| 位置情報や写真の位置データを扱う | 利用目的の特定と同意。写真の位置情報を取り除くかを検討 | 個情法17条 |
| 要配慮個人情報に触れる（健康状態、労災、前科など） | **原則として取得に本人の同意が必要**。漏えい時は1件でも報告対象。扱わない設計にするのが最善 | 個情法20条2項・26条 |
| 16歳未満が登録しうる形にする | 同意取得や通知を法定代理人に対して行う規律（改正法案で明文化予定）。規約で年齢要件を明示しておく | 改正法案 |
| 海外の会員や海外への情報提供が発生する | 外国にある第三者への提供の検討。同意取得または基準適合体制の確認 | 個情法28条 |

| きっかけ | すべきこと | 根拠 |
|---|---|---|
| 退会の機能を実装する | ①退会後のデータの扱いをポリシーに書く（**済**：第9項） ②退会と利用停止を状態として扱えるようにする（現在は運営が手作業） ③規約第13条の退会条項を実際の操作に合わせて見直す ④退会後も規約・ポリシー・問い合わせ案内が読めることを確認（**済**：proxy.ts の公開パス） | 個情法22・35条 |

| 取材記事を増やす | ①取材時に公開範囲を示して同意を得て記録 ②顔写真・動画は肖像権も確認 ③現場写真に施主が写る場合は施主の同意 ④掲載停止の申し出への対応（規約第12条） | 個情法27条・肖像権 |

## E. 外部環境

| きっかけ | すべきこと | 根拠 |
|---|---|---|
| 漏えい・不正アクセスが疑われる | 社内の初動手順に従う。報告対象の類型（要配慮個人情報／財産的被害のおそれ／不正の目的による行為／1,000人超）に該当すれば、**速報は発覚から3〜5日以内、確報は30日以内（不正の目的による場合は60日以内）**に個人情報保護委員会へ報告。本人への通知の要否も判断 | 個情法26条 |
| 個人情報保護法の改正が施行される | 委託先の義務の明文化、漏えい時の本人通知の緩和、顔特徴データ、16歳未満の規律などを確認してポリシーと運用を更新。**2026年7月17日に公布済み。施行は原則として公布から2年以内の政令で定める日（一部の規定は先に施行）。政令・規則・ガイドラインが公表されたら、施行日と内容を確認する** | 令和8年改正法 |
| 外部サービスのリージョンや契約条件が変わる | ポリシー第7項「外的環境の把握」のサーバ所在国を更新 | 個情法32条1項4号 |
